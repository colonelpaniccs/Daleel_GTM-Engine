# Contributing

This is a solo-maintained, documentation-only repository. The two notes below cover what it does and doesn't accept.

> [!IMPORTANT]
> **Nothing here to build against.** No implementation code, prompt library,
> scoring logic, or signal source is included in this repository.

> [!NOTE]
> **Pull requests** aren't accepted, since this repo mirrors decisions made
> in a private working repository. For questions about architecture or
> design reasoning, submit an issue.
